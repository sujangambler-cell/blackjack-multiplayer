Layout rules for 9:16 mobile

  • Top bar (fixed height ~48px) — Leave / room code / player count / balance. Never overlaps the table.
  • Middle = game stage (flex: 1) — Felt or wheel + betting grid. Everything centered. No horizontal scroll.
  • Bottom dock (thumb zone) — Chips + primary actions (Hit/Stand or Spin/Leave). Min touch target ~44–48px.
  • Blackjack — Dealer at top of felt, shoe top-right, players along bottom arc of felt, dock under felt.
  • Roulette — Compact wheel on top third, number grid + outside bets in middle (scroll only if needed), dock fixed at bottom with Clear / Spin / Leave always visible.
  • Leave always reachable without opening Settings (bottom bar on Roulette, top-left / settings on Blackjack).
  • Aspect ratio of the phone frame above is exactly 9 / 16 — this is the target canvas for all mobile UI work.
