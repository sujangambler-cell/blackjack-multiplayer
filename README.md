# Blackjack — Day 14 Final

Final admin command-center build for the current Blackjack multiplayer project.

## Included
- Multiplayer blackjack with public/private tables
- Persistent accounts, friends, chat, stats, rankings, achievements and daily rewards
- Host controls and player kicking
- Dealer hole-card protection and blackjack resolution
- Responsive dark/light casino table themes
- PC/Phone graphics profile, GUI scale and SFX settings
- Admin button on the table near Host controls
- Password-protected admin command center
- Admin economy controls: give, set, reset and table bonuses
- Player management: kick, mute and lucky mode
- Table controls: dealer preview, shoe reshuffle, round reset and pause/resume between rounds
- Live admin dashboard: online players, active tables, accounts and chips in circulation
- Live events: Double XP and Bonus Cash
- Per-account progress wipe for testing/admin maintenance

Admin access uses the `ADMIN_PASSWORD` environment variable on the server.
